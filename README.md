# 看剧 · LibreTV 本地版

两个东西，各管一头：

| | 是什么 | 放在哪 |
|---|---|---|
| **看剧 App** | 安卓手机应用，装机即用，自己带片源管理、投屏、离线下载 | `apk/kanju-5.3.1.apk` |
| **LibreTV 本地版** | 电脑上跑的网页版观影服务，浏览器访问 | `libretv/LibreTV-local-20261127.zip` |

**两个包都不带播放源**，需要你自己填。播放源地址在本文档「三、播放源」一节，开头有 7 条**推荐使用**，复制粘贴即可。

### 在上游基础上加了什么

主要是三件事：

1. **分片下载**：把「播放器要一片才去拉一片」改成多线程并发抓取。源站对单连接限速（实测 110~140 KB/s），并发才能把带宽用起来。手机端的离线下载也走这套，8 路并发实测 16.67 MB/s。
2. **分片缓冲**：后台预取池提前把后续 10 片抓好，配合磁盘缓存和带上限的内存缓存（超了自动淘汰）。播放器取片从「每片等 5 秒」变成「命中缓存毫秒级」。投屏时电视拉分片同样吃这层缓存，实测每片 4 秒降到约 130 毫秒。
3. **更多源**：实测了 73 个采集站域名，可用与不可用的都整理进文末清单；并做了自定义源管理，可随时增删、探活，分类按名称归一（各源的分类 ID 含义并不统一）。

另外，手机 App（`apk/`）的界面、内置 HTTP 服务器、DLNA 投屏是照着 LibreTV 的思路自己写的，没有直接复用它的代码。

### 二次分发

请保留上面三个上游项目的署名与许可声明。LibreTV 是 MIT、hls.js 是 Apache-2.0，两者都要求保留版权声明。

## 一、看剧 App（安卓）

### 装

1. 把 `apk/kanju-5.3.1.apk` 拷到手机（数据线、QQ、微信、网盘都行）
2. 点开它，系统会提示「未知来源」，允许一次
3. 桌面上出现「看剧」图标

系统要求：**Android 7.0 及以上**。荣耀、小米、华为、OPPO、vivo 都测过能装。

### 第一次用：先加片源

装完是空的，这是故意的（不带源才好公开）。加源只要三步：

1. 打开 App → 底部点 **影片库** → 右上角 **⚙**
2. 在「添加片源」填两格：
   - **名称**：随便写，留空就自动用域名
   - **地址**：从本文最后「播放源」一节复制一条粘进去
3. 点 **＋ 添加**

地址三种写法都认，不用纠结：

```
caiji.moduapi.cc
https://caiji.moduapi.cc/api/
https://caiji.moduapi.cc/api.php/provide/vod
```

上面三种填进去效果一样，程序会自动补全成完整接口。

加完立刻生效，回影片库就有内容了。**建议一次加 3~5 条**，一条挂了还有别的顶着。

### 能干什么

**影片库**
底部导航第一条。顶部一排分类（电影、电视剧、国产剧、日韩剧、动漫、综艺、纪录片等），左右滑动切换。往下滚动会自动加载下一页，加载时底部有骨架卡和「正在加载新电影…」，不会让你对着空白等。

**搜索**
只在影片库页显示。搜片名、演员名都行，多个源同时搜，结果合并去重。

**详情 / 播放**
点海报进详情页，能看到简介和全部剧集。点集数开始播。

播放页功能：

- 点屏幕唤出控制栏（3.6 秒后自动隐藏）
- **倍速** 0.5× ~ 2.0×
- **选集面板**：右上角，一次列出全部集
- **自动下集**：一集播完自动接下一集，设置里能关
- **断点续播**：退出再进来，从上次的位置接着放
- **画质/线路切换**：同一部片有多个源，卡了换一条

**榜单**
底部第二条。8 个豆瓣榜单：Top250、正在上映、实时热门电影、一周口碑电影、实时热门剧集、华语口碑剧集、全球口碑剧集、华语口碑综艺。点任意一条 → 自动去片源里找这部片 → 直接进详情页。

**随便看**
底部第三条，抽签决定看什么：

- **想看什么**：电影 / 电视剧 / 都行
- **不低于 N 分**：豆瓣评分门槛，默认 4.0
- **屏蔽低于这个分数的**：上面那个分数生不生效
- **抽过的不再抽**：抽过的片记进下方列表，下次跳过；关掉这个开关，列表消失、不再记录

点「抽一个」，卡片先快速轮播再减速，**2 秒**定格。

评分输入有校验：`4`、`4.0`、`4.5` 都行；`1.25`、`-1`、`10`、`1.`、`abc` 会被拒绝并提示。

**收藏 / 历史**
点详情页的心形收藏，底部「收藏」页能看到。看过的片自动进历史，每条右边有 ×，顶部有「清空记录」（要连点两次确认）。搜索历史同理。

**离线下载**
播放页点「下载」，或在详情页长按集数。

- 选下载目录：默认存 App 私有目录（不占相册、不用权限）；也可以点「选目录」存到手机任意文件夹（走系统文件选择器，选一次就记住）
- **8 路并发下载**，实测 600MB 一集约 36 秒（16.7 MB/s）
- 下载时会挂一条常驻通知，这是安卓的硬性要求，不然系统几分钟就把后台掐了
- 下完在「下载」页能直接播，本地播放不需要网络

**投屏（DLNA）**
播放页控制栏点「投屏」，会自动搜索同一 WiFi 下的电视 / 盒子 / 电脑。

- 投上之后手机自动出现一个**悬浮遥控胶囊**，点开能：暂停/继续、±10 秒、±30 秒、拖进度、调音量、切上一集/下一集、停止投屏
- 悬浮窗不用回到 App，退到桌面照样能控制
- **兼容模式**：老电视不认 HLS（.m3u8）的话，打开这个开关，整集拼成一条 MPEG-TS 流推过去。能播，但拖进度会回到开头

投屏期间手机不能杀 App 进程（会挂前台通知保活），电视自己要拉片源，得靠手机中转。

**设置**
影片库右上角 ⚙。里面能管理所有片源（含自定义的增删）、看各源健康状态、关自动下集等。

### 权限说明

首次启动会一次性申请：

- **通知权限**：下载和投屏要在通知栏挂常驻通知，不然会被系统杀
- **悬浮窗权限**（显示在其他应用上层）：投屏遥控胶囊需要

两个都允许一次就好，之后不再打扰。**覆盖安装会把悬浮窗权限重置**，如果装新版后看不到遥控胶囊，去设置里再开一次。

App 不需要存储权限（用系统文件选择器）、不需要通讯录、不需要定位。

## 二、LibreTV 本地版（电脑）

### 装

1. 解压 `libretv/LibreTV-local-20261127.zip` 到任意目录
2. 确保电脑装了 **Node.js 18 以上**
3. 双击 `start-localtv.ps1`（右键 → 使用 PowerShell 运行）

脚本会自动起两个服务，就绪后打开浏览器。

| 服务 | 端口 | 作用 |
|---|---|---|
| HLS 加速器 | 3001 | 分片并发预取，解决源站单连接限速 |
| LibreTV | 3000 | 主界面 |

地址：`http://127.0.0.1:3000`
密码：`040118`

**只监听回环地址，同一 WiFi 下的其他设备访问不了**，这是故意的。要改密码，编辑 `start-localtv.ps1` 里 `PASSWORD` 那一行。

### 加片源

登录后 → 右下角设置 → 源管理 → 点播源 → 添加 API。

**只填域名部分，不要带 `/api.php/provide/vod`**：

```
https://caiji.moduapi.cc
```

### 为什么要有那个「加速器」

这类采集站普遍对**单条连接**限速在 110~140 KB/s，而播放器是一个分片一个分片顺序取的，永远只能吃这么多。高清片源码率 2000 kbps 需要 250 KB/s，必然卡。

加速器的做法是：播放器要第 N 片时，它已经用多线程把 N+1 到 N+10 拉下来了。实测顺序播放平均吞吐从 110 KB/s 提到 **1167 KB/s**。

### 首片为什么还是慢

源站单连接限速是硬限制，第一片没有预取可借，**约 3 秒**。之后就是连续的了。

### 这个 ZIP 里的关键设置

`start-localtv.ps1` 里有三个地方别乱改：

1. **`LIVE_ALLOW_PRIVATE=1`**：LibreTV 自带 SSRF 防护，没这个变量它会把指向 `127.0.0.1` 的加速源当非法地址拒掉，加速直接失效
2. **`HOSTNAME=127.0.0.1`**：不设的话默认监听 `0.0.0.0`，同一局域网都能访问
3. **`NODE=...`**：node 路径。换电脑要改这一行

### 怎么验证一条源能不能用

把地址拼成这样，浏览器直接打开：

```
https://某域名/api.php/provide/vod/?ac=videolist&wd=测试
```

- 返回一坨 **JSON**，里面有 `"list":[...]`，每条带 `vod_play_url` → 能用
- 返回 HTML / 跳验证码 / 超时 → 不能用

### 怎么自己找新源

- 搜索引擎搜「苹果CMS 采集站」「影视采集接口」「CMS 资源站」
- GitHub 搜 `cms 采集` `影视 接口`
- 一些 TG 频道和资源站会定期更新列表

### 踩过的坑（自己找源时用得上）

1. **分类参数是 `t=`，不是 `type_id=`**。用 `type_id=` 会被大部分源**直接忽略**，返回「最新更新」冒充分类结果——现象就是「点了电影出来一堆电视剧」
2. **`ac=detail` 才带播放地址**，`ac=list` 只有摘要
3. **各源的分类 ID 含义完全不同**。A 源的 `1` 是电影，B 源的 `1` 可能是动漫。不能当全局常量写死，必须按分类名归一
4. **同一部片在不同源叫不同名字**（「流浪地球2」/「流浪地球Ⅱ」），要模糊匹配才能合并成「多线路」
5. **存活率很低**。这批 73 个里当下只活 10 个，约 14%。别指望找到「长期稳定」的源

## 四、常见问题

**Q：装了 App，打开一片空白？**
A：没加片源。按第一节「第一次用」加几条。

**Q：搜索没结果？**
A：先确认片源健康（设置里看状态点是不是绿的），再换个关键词试试。有些源只收国产剧，搜外国片搜不到。

**Q：播放卡 / 一直转圈？**
A：换线路。同一部片通常有 3~5 个源，详情页能切。这个是源站限速问题，不是 App 的问题。

**Q：投屏搜不到设备？**
A：确认手机和电视连的是同一个 WiFi（不是同一个也行，但要能互通）。重搜几次，SSDP 有丢包。有些电视需要在设置里手动开启「DLNA」或「媒体共享」。

**Q：投屏上了但电视黑屏 / 提示格式不支持？**
A：打开「兼容模式」再投一次。老电视普遍不认 HLS。

**Q：下载的片子在哪？**
A：默认在 App 私有目录，卸载 App 一起删。想放到相册或者别的文件夹，在下载设置里点「选目录」，用系统文件选择器指定位置。

**Q：为什么下完才能播？**
A：下载是整集下完才生成播放清单，不支持边下边看。要边下边看直接用在线播放。

**Q：装新版后遥控胶囊不见了？**
A：覆盖安装会重置悬浮窗权限。去 设置 → 应用 → 看剧 → 权限，把「显示在其他应用上层」打开。

**Q：会不会收集我的数据？**
A：不会。App 没有联网上报，所有数据（收藏、历史、搜索记录、片源配置）都存在你手机本地。唯一的外部请求是向你自己配置的片源和豆瓣公开接口取数据。

## 六、技术栈

**App**：Java（无第三方依赖，纯手工 aapt2 + javac + d8 构建链）+ WebView 前端。APK 体积 250KB。内置 HTTP 服务器（端口 8686）处理搜索聚合、片源管理、HLS 分片代理、DLNA 投屏。

**LibreTV 本地版**：[LibreSpark/LibreTV](https://github.com/LibreSpark/LibreTV) v2.24.0（MIT） + [hls.js](https://github.com/video-dev/hls.js)（Apache-2.0） + 自写的 HLS 并发预取代理（分片下载 / 分片缓冲 / 多源聚合）。

关键实现：

- 分片并发预取：播放器顺序取片时，后台已把后续 10 片拉好
- 投屏走手机代理中转：源站有 Referer 防盗链，电视自己连会被拒
- 源健康检查：连续失败自动标灰，不拖慢搜索
- 分类按名称归一：各源的类型 ID 含义完全不同，不能当全局常量写死
